# Agent Reach Is Vendored as a Skill

## Why Care?

[Agent Reach](https://github.com/Panniantong/Agent-Reach) gives an agent read-only access to platforms that web search and fetch handle badly: Twitter/X, Reddit, YouTube subtitles, GitHub, LinkedIn jobs, Instagram, Bilibili, Xiaohongshu, V2EX and stock quotes. It never posts, and never asks for passwords.

## What changed

- **Mounted** `Panniantong/Agent-Reach` (MIT) as the submodule `agent-reach` at `c70ae6d`. It is upstream code: never commit inside it.
- **Excluded from Stow**, because the skill sits one level down at `agent-reach/agent_reach/skill/`. Link it by hand:
  `ln -s <mono-root>/context-v/agent-skills/agent-reach/agent_reach/skill ~/.claude/skills/agent-reach`
- The default `SKILL.md` is written mostly in Chinese; `SKILL_en.md` beside it is the English version.

The skill drives a Python CLI (`agent-reach`), which still has to be installed separately before the skill can do anything.
