# Vendored Skills Get Their Own Section on the Splash

## Why Care?

The splash is where people see what we've built. Mixing in Archify, Graphify, Floorplan and the rest made other people's work look like ours, and pushed our own skills down the landing page.

## What changed

- **A Vendored page** at `/vendored/`, linked from the header and footer, lists the 9 skills we use from other people, each with the repo it comes from.
- **The landing page and the Skills catalog show only ours**: 38 skills. The catalog links across to Vendored.
- **How a skill counts as vendored:** its folder is a git submodule listed in `.gitmodules`, or it carries a `VENDORED.md` (graphify). Nothing to tag by hand; vendoring a new skill puts it in the right section.
- **Vendored skill pages link to their source repo.** "View on GitHub" used to build a path inside this repo, which 404s for a submodule. They now show a Vendored pill and go back to the Vendored list.
