# Lossless Skills v0.0.0.1: Four Skills Shipped, Backlog Wired

This repo didn't exist when the session started. It does now, on GitHub at [`lossless-group/lossless-skills`](https://github.com/lossless-group/lossless-skills), with four shipped Agent Skills, a running backlog of candidates, and the first version of the kind of changelog you're reading.

## What's new

### Four shipped skills

- **[`context-vigilance/`](../context-vigilance/)** — codifies the `context-v/` framework: six folders organized into Planning (specs ↔ prompts), Reflective (blueprints ↔ reminders), and Journey (explorations, issues) modes; four-part `epoch.major.minor.patch` versioning; Train-Case filenames and tags; the "norms not rules" ethos. Reference docs cover [philosophy](../context-vigilance/references/philosophy.md), [versioning](../context-vigilance/references/versioning.md), [frontmatter spec](../context-vigilance/references/frontmatter-spec.md), and [a doc-type decision guide](../context-vigilance/references/doc-type-guide.md). Six templates (one per folder type).
- **[`astro-knots/`](../astro-knots/)** — the vision-mission and tech conventions for the family of ~10+ Astro sites: the Tech Hierarchy (HTML & CSS first, then vanilla JS, then a small focused package, then a framework — only the approved few), the approved list (Astro, Svelte, GSAP, Reveal), the hard prohibitions (React, JSX, Angular, "bloat"), and the build-in-public + meaningful-content-while-shipping principles.
- **[`pseudomonorepos/`](../pseudomonorepos/)** — the coined Lossless term for parent repos that aggregate child repos (often as submodules) primarily to host parent-level `context-v/`. Encodes the **search-first-before-creating** behavioral discipline: walk the tree, find prior work, surface findings, link rather than duplicate. Includes a snapshot of the current `lossless-monorepo` tree (anchor + four ranked children) and the [5-phase lifecycle workflow diagram](../pseudomonorepos/references/lifecycle-workflow.md) that ties everything together.
- **[`changelog-conventions/`](../changelog-conventions/)** — what you're reading the output of. Frontmatter contract (`date_created`, `date_modified`, `title`, `lede`, `publish: true`, `authors:` as ul list), filename pattern (`YYYY-MM-DD_NN.md`), `releases/` subfolder for product-style projects, "show don't enforce" ethos, and the future "tweet-style" candidate.

### Repo infrastructure

- **Public GitHub org repo:** [`lossless-group/lossless-skills`](https://github.com/lossless-group/lossless-skills), MIT licensed
- **README** with install instructions for pi, Claude Code, and Codex
- **["Built in public"](../README.md#built-in-public)** section tying this work to the broader Lossless "Lost in Public" practice
- **[`CANDIDATES.md`](../CANDIDATES.md)** — running backlog of potential future skills, including `lfm`, `lossless-loop`, `obsidian-integration`, `submodule-hygiene`, `astro-component-patterns`, `lossless-house-style`, `monorepo-nav`, plus emerging candidates from active studies (`study-pattern`, `profiles-doctype`)

## Why it matters

Three reasons this matters beyond "we made some skills":

1. **The skills compose, not stack.** Working on any task in `lossless-monorepo` now triggers `pseudomonorepos` (search first, walk the tree), `context-vigilance` (write to the right folder, with the right frontmatter), `astro-knots` (respect the tech hierarchy, refuse React), and now `changelog-conventions` (log when you ship). Each skill loads on-demand; together they form a coherent collaborator persona.

2. **The framework is honest about itself.** Every skill explicitly acknowledges where reality diverges from aspiration: "most pseudomonorepos are imperfectly maintained," "frontmatter is scattered," "ship-fast is allowed but log refactor debt." This is the difference between rules and norms — the docs name the gap rather than pretending it isn't there.

3. **The work is portable.** These skills follow the [Agent Skills standard](https://agentskills.io/specification), so they work in pi, Claude Code, OpenAI Codex, or anything else that reads `SKILL.md`. The Lossless conventions are now installable.

## What's next

Once those converge, a comparative blueprint will fold into `context-vigilance`.
