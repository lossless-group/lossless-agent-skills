# The Astro Knots Skill Pack Gets Its Own Repo

## Why Care?

Someone who only builds Astro sites can now clone or fork
[astro-knots-skills-pack](https://github.com/lossless-group/astro-knots-skills-pack)
and get the nine skills they need, without the CRM guides and VC memo methods
that share this repo.

## What changed

- **`skill-packs/astro-knots/`** is a submodule of
  `lossless-group/astro-knots-skills-pack`. Each skill's commits came with it.
- **Names didn't change.** The sync scripts still link each skill as
  `~/.claude/skills/<name>`.
- **Links follow the pack.** On GitHub a path inside a submodule is a pointer,
  not a folder, so this site's source links, the README table and the pack's
  own links to skills outside it now point at the right repo.
- **Clone with submodules:** `git clone --recurse-submodules`, or
  `git submodule update --init` afterwards.
