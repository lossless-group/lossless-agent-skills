## Why Care?

The astro-knots splash rendered 227 pages as a title over an empty body for
months, and its code blocks never got LFM's new colors. Nothing in the LFM
skill would have stopped an agent making the same mistakes, and its install
steps pointed at `@lossless-group/lfm-astro`, which isn't on JSR.

## What's New?

- **"Rendering: the hard rules"** in `lossless-flavored-markdown`: bodies go
  through `parseMarkdown` and `AstroMarkdown`, never `render()` alone; code is
  colored with `@lossless-group/lfm/highlight`; components come from
  `astro-knots/packages/lfm-astro/components/`; check the output, not the
  status code.
- **Install steps that work:** the JSR alias with an `.npmrc`, then copy the
  components. `@lossless-group/lfm-astro` returns 404 on JSR.
