## Why Care?

There was no folder for a document that answers "what's actually running?"
A deployment's services, a Railway project's topology, the shape of a live
pipeline: specs say what we intend, and blueprints say how something is
designed. Neither one goes stale the way a live system does, and neither one
says when it was last checked. The `sitemap/` folder came closest, but the
word only fits websites.

***

## What's New?

- **`mirrors/` joins the experimental tier.** A mirror reflects what's
  built and running now. It records `date_mirrored` and `mirrors:` (its
  source), ends with how to re-take it, and is re-taken rather than edited
  from memory when it drifts.
- **The which-folder list has a line for it**, and the skill's description
  lists it.
- **`sitemap/` is now described as a website-shaped mirror.** Mirrors may
  absorb it eventually; nothing migrates yet, so existing sitemaps stay put.

The first mirror is `dididecks-ai/context-v/mirrors/Railway-Setup-for-AIStack-AIDecks.md`.
